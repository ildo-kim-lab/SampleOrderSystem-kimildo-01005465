# CURRENT_PLAN.md (이번 증분)

## 목표 (기능 누락 수정, 이어지는 증분)
"생산 라인"을 단순 표시(생산 현황 + 대기 주문, 조회만 가능)에서 실제로
동작을 실행할 수 있는 하위 메뉴로 바꾼다: 1. 생산 현황, 2. 대기 주문
확인, 3. 생산 완료 처리, 0. 뒤로가기.

## 검증할 동작
`run_app`에서 "생산 라인"(5번)을 선택하면 하위 메뉴가 뜨고, "3"(생산 완료
처리)을 선택하면 `complete_next_production_console`이 호출되어 큐의
맨 앞 주문이 실제로 CONFIRMED로 전환된다.

## 근거
- 이전 증분에서 만든 `complete_next_production_console`을 실제 메뉴에서
  호출할 수 있어야 발견 목록 4번("생산 완료 처리를 실행할 메뉴가 없음")이
  완전히 해결된다.

## 범위 외
- 없음. 이 증분으로 발견 목록의 4개 항목이 모두 마무리된다.

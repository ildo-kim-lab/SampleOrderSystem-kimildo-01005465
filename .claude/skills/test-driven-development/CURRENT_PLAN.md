# CURRENT_PLAN.md (이번 증분)

## 목표 (버그 수정)
시료관리/주문 서브메뉴에 진입하면 메뉴 항목(등록/조회/검색 등)이 화면에
전혀 출력되지 않아, 사용자가 무엇을 입력해야 하는지 알 수 없는 문제를
고친다. 메인 메뉴처럼 서브메뉴도 매 반복마다 항목을 출력한다.

## 검증할 동작
`run_sample_menu`를 호출하면, 입력을 요청하기 전에 "등록"/"조회"/"검색"/
"뒤로가기" 항목이 포함된 메뉴 텍스트가 `output_func`로 출력된다.

## 근거
- 사용자가 직접 실행해보고 발견한 버그: 서브메뉴에서 "선택:"만 뜨고
  무엇을 선택해야 하는지 안내가 없음.

## 범위 외
- `run_order_menu`의 동일한 수정은 같은 증분에서 함께 처리한다 (원인과
  해결책이 완전히 동일하므로 분리하지 않는다).

# CURRENT_PLAN.md (이번 증분)

## 목표 (버그 수정)
`search_samples`가 시료 이름(name)뿐 아니라 시료 ID(sample_id)도 검색
대상에 포함하도록 고친다.

## 검증할 동작
`search_samples`를 시료 ID에 포함된 키워드(예: 더미 데이터의 "S-001"에
포함된 "001")로 호출하면, 이름에는 키워드가 없어도 해당 시료가 결과에
포함된다.

## 근거
- `docs/PRD.md` 5.2 시료관리 — "시료 검색: 이름 **등 속성**으로 특정
  시료를 검색"
- 사용자가 직접 실행해보고 발견한 버그: 검색어로 "1"을 입력했는데
  ("S-001" 등 ID에 "1"이 포함돼 있음에도) 결과가 하나도 안 나옴 — 이름
  ("Wafer-A" 등)만 검색하고 있었기 때문.

# 반도체 시료 생산주문관리 시스템 (SampleOrderSystem)

## 1. 배경 및 목적

S-semi 반도체 회사의 시료(Sample) 생산 주문을 관리하기 위한 **콘솔 기반** 시스템이다.
주문 담당자가 고객의 시료 주문을 접수하고, 생산 담당자가 승인/거절 및 생산 라인을 통해
시료를 생산·출고하는 전체 흐름을 하나의 프로그램에서 처리한다.

## 2. 대상 사용자

- **주문 담당자**: 시료 등록, 주문서 작성/관리, 출고 처리
- **생산 담당자**: 주문 승인/거절, 생산 라인 및 재고 모니터링

두 역할은 별도 로그인 없이 동일한 콘솔 메뉴에서 조작한다고 가정한다 (역할 기반 접근 제어는 범위 외).

## 3. 용어집 (Glossary)

| 용어 | 설명 |
|---|---|
| 시료 (Sample) | 시스템의 기본 단위. 고유 이름, 속성(평균 생산시간, 수율)을 가짐 |
| 재고 (Stock) | 시료별로 현재 출고 가능한 보유 수량 |
| 생산 라인 (Production Line) | 시료를 하나씩 생산하는 설비. 생산 큐(FIFO)를 가짐 |
| 생산 큐 | PRODUCING 상태 주문이 대기하는 FIFO 큐 |
| 수율 (Yield) | 생산 시 실제 사용 가능한 양품 비율 |

## 4. 주문 상태 (State Machine)

모든 주문은 다음 5개 상태 중 하나를 가진다.

| 상태 | 의미 |
|---|---|
| `RESERVED` | 주문 접수 (초기 상태) |
| `REJECTED` | 주문 거절 (종료 상태, 모니터링 대상 제외) |
| `PRODUCING` | 승인 완료, 재고 부족으로 생산 중 |
| `CONFIRMED` | 승인 완료, 재고 충분 또는 생산 완료, 출고 대기 |
| `RELEASED` | 출고 완료 (종료 상태) |

### 상태 전이

```
RESERVED --(거절)--> REJECTED
RESERVED --(승인, 재고 충분)--> CONFIRMED
RESERVED --(승인, 재고 부족)--> PRODUCING
PRODUCING --(생산 완료)--> CONFIRMED
CONFIRMED --(출고 처리)--> RELEASED
```

- `REJECTED`, `RELEASED`는 종료 상태이며 이후 상태 변경 불가
- `REJECTED`는 정상 흐름 외 상태로 모든 모니터링/집계에서 제외

## 5. 핵심 기능 요구사항

### 5.1 메인 메뉴
- 전체 시료 요약 정보를 표시
- 하위 메뉴: 시료관리 / 주문(접수·승인·거절) / 모니터링 / 출고 처리 / 생산 라인

### 5.2 시료관리
- **시료 등록**: 입력값 — 시료 ID, 이름, 평균 생산시간, 수율
- **시료 조회**: 등록된 전체 시료 목록 + 현재 재고 수량 표시
- **시료 검색**: 이름 등 속성으로 검색

### 5.3 시료 주문 (예약)
- 입력값: 시료 ID, 고객명, 주문 수량
- 생성 시 상태는 `RESERVED`

### 5.4 주문 승인/거절
- `RESERVED` 상태 주문 목록 표시
- **승인**:
  - 재고 충분 → 즉시 `CONFIRMED`
  - 재고 부족 → 생산 라인에 등록, `PRODUCING`으로 전환
- **거절**: 즉시 `REJECTED`로 전환

### 5.5 모니터링
- **주문량 확인**: 상태별(`RESERVED`/`CONFIRMED`/`PRODUCING`/`RELEASED`) 주문 목록 (`REJECTED` 제외)
- **재고량 확인**: 시료별 현재 재고 수량과 주문 대비 상태
  - 여유: 재고가 주문 수요 대비 충분
  - 부족: 재고가 주문 수요 대비 부족하지만 0 초과
  - 고갈: 재고 수량 0

### 5.6 생산 라인
- 생산 라인은 시료 하나를 생산하는 설비 흐름을 가지며, `PRODUCING` 주문만 처리
- 실 생산량 계산: `실 생산량 = ceil(부족분 / 수율)`
- 총 생산 시간 계산: `총 생산 시간 = 평균 생산 시간 * 실 생산량`
- 생산 완료 시 해당 주문 상태 `PRODUCING` → `CONFIRMED`
- **생산 현황 표기**: 현재 생산 중인 시료, 관련 주문 정보, 현재까지 생산량 표시
- **대기 주문 확인**: 생산 큐(FIFO)의 대기 목록 표시

### 5.7 출고 처리
- `CONFIRMED` 상태 주문 대상으로 출고 실행
- 실행 시 상태 `CONFIRMED` → `RELEASED`

## 6. 비기능 요구사항

- 콘솔(CLI) 기반 대화형 인터페이스로 동작
- 단일 프로세스 내에서 순차적으로 명령을 처리 (동시성/멀티유저 고려 안 함)
- 데이터는 프로세스 실행 중 메모리 상에서 관리 (영속화 방식은 구현 단계에서 결정)
- 상태 전이는 반드시 정의된 상태 머신을 따르며, 잘못된 전이는 허용하지 않음

## 7. 범위 외 (Out of Scope)

- 사용자 인증/권한 관리 (역할 구분 없음)
- 다중 생산 라인 스케줄링 최적화 (현재는 단일 생산 라인, FIFO만 고려)
- 외부 시스템 연동(ERP, 알림 등)
- 웹/GUI 인터페이스

## 8. 성공 기준 (Acceptance Criteria)

- 시료 등록 → 주문 접수 → 승인(재고 충분/부족 각 케이스) → (생산 완료) → 출고까지
  전체 흐름이 상태 머신 정의대로 동작한다.
- 재고 부족 시 생산 라인에 정확한 실 생산량/생산 시간이 계산되어 등록된다.
- 모니터링 메뉴에서 `REJECTED` 주문이 집계에서 제외됨을 확인할 수 있다.
- 생산 큐가 FIFO 순서로 처리됨을 확인할 수 있다.
